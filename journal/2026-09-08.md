# 2026-09-08 — paper figures, the big restyle

Objective: bring all paper figures to publication standard (Sophie's rules:
modern, no titles, panel labels "A.", fonts at caption size, thin horizontal
colorbars below, consistent sizes, textwidth).

## Infrastructure
- `paper/figures/paperfig.py`: shared style (W1/W2 = 8.5/17.5 cm, model
  colors, panel_label, thin colorbar). All figures are true-size vector PDFs
  included without scaling, so printed fonts are exact.
- Build recipe per script header; torch scripts need the NVIDIA
  LD_LIBRARY_PATH block even on CPU (login-node safe, ~1–2 min each).

## The set (paper order)
1. Domain map (`fig1a_domain.py`): PW frame, map axes exactly textwidth,
   lat labels in the margin, red example block; colorbar
   "Precipitable Water [mm], standardized (PW−μ)/σ".
2. Two-head U-Net = the exact html SVG (`unet_page.svg` extracted, CSS vars
   flattened, rsvg-convert → PDF) + input stack (10 channels, rain last,
   blue-framed, per-map colorbars) and output pair (rain + wet/dry prob) via
   `fig2_io.py`. Finding: wet/dry head near-saturated (dry mean 0.85 — BCE
   against y>0); stated in the caption.
3. Flow-matching schematic (`fig3_flowsketch.py`, from Sophie's notebook
   sketch): forecast → flow box (c inside, 10-channel conditioning) → two
   aligned draws | truth; dashed zoom panel encloses the transport integral
   and a block-diagram integrator (v̂θ → ×Δt → ⊕, bypass, repeat ×32,
   Δt = 1/32). Replaced the picture-book strips.
4. Pairs triptych (`fig3_pairs.py`): full-textwidth panels, colorbar
   aspect 110 / shrink 0.8 on its own axis, legend beneath.
5. Horizon centerpiece (`fig5_horizon.py`): 2×2 at W2×0.98 — POD/FAR(+3 h),
   POD(t;L) with direct band labels, τ(L) with the three fits; panel D full
   size with its own colorbar below.
6. Decomposition pair (`fig4_decomp.py`): full-record clouds, barycenter
   crosses colored by the colorbar's own viridis scale (L = 40/115/450 km).
7. WB2 (`fig6bc_wb2.py`): +12 h POD panel + month clouds; belt/zoom maps
   still the old raster assets (only remaining restyle debt).
