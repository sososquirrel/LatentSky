# Journal

One file per day: `journal/YYYY-MM-DD.md`. Written by Claude and Sophie at the end of every working
session (and on request with `/journal`), read at the start of the next one.

Purpose: a lab notebook. Someone opening the repo in six months — Sophie, a collaborator,
a reviewer — must be able to reconstruct what was tried, why, and what was concluded,
without reading code or chat history. Concise, but nothing omitted that changed a decision.

Rules
- Facts and numbers only. A result without a number is not written down.
- Every experiment run that day gets an entry, including failed and inconclusive runs.
- Link to files, never paste code: `experiments/2026-09_tau_fitform/`, `results/fig_R2.py`.
- Never rewrite a past day. Corrections go in today's entry with a pointer back.
- `journal/INDEX.md` is regenerated by `/journal`: one line per day, plus the current
  status of R1–Rn.
