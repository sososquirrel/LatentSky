  `train_diffusion.py` retracted it: the diffusion trainer ignores `split_mode` and
  unconditionally builds the patch split (seed 1919810, 70/15/15) — identical to the
  one-head runs. The manifest field is a misleading unused default; no retraining
  needed. Lesson: manifests record the config, not the code path.

  the model receives the persistence forecast as an input channel); out-of-scope line
